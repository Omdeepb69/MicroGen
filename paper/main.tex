\begin{abstract}
Large Language Model (LLM) serving frameworks rely on diverse optimizations---including Paged Key-Value (KV) memory allocation, continuous request batching, prefix caching, weight quantization, speculative decoding, and tensor parallelism---to improve inference throughput and reduce latency. However, state-of-the-art serving engines typically bundle these optimizations into monolithic C++/CUDA frameworks, masking individual performance trade-offs and non-monotonic combinatorial interaction boundaries. In this paper, we present \textsf{MicroGen}, a modular, hardware-aware execution substrate and empirical research framework designed to isolate, benchmark, and analyze LLM serving optimizations under controlled workload, hardware, and measurement conditions. Rather than proposing a production serving engine, \textsf{MicroGen} provides a common modular interface to conduct isolated micro-ablations using an $N=30$ repeated-trial evaluation protocol across NVIDIA Tesla T4 and P100 GPUs and open-weights model families (GPT-2, Qwen2.5, Llama-3.2). Our empirical findings reveal two primary discoveries: (1) Shared-prefix caching achieves up to a \textbf{3.91$\times$ TTFT prefill latency speedup} (reducing prefill TTFT from $25.8 \pm 1.2\text{ ms}$ to $6.6 \pm 0.3\text{ ms}$, $p_{\text{adj}} < 0.001$) under 100\% prompt overlap at $L_{\text{prompt}}=1024$ tokens, crossing into positive speedup once prompt overlap exceeds 25\%; (2) Crucially, optimization composition is non-monotonic: combining individually beneficial optimizations (+INT8, +Paged KV, +Prefix Cache) produces a statistically significant throughput regression ($493.6 \pm 8.6\text{ tok/s}$, $0.96\times$ baseline, $p_{\text{adj}} < 0.001$), while full continuous serving stack concurrency drops throughput to $0.76\times$ baseline ($391.8 \pm 6.2\text{ tok/s}$, $p_{\text{adj}} < 0.001$) due to cumulative scheduler and pointer indirection overheads. We release \textsf{MicroGen} open-source to support transparent, data-driven LLM inference systems design.
\end{abstract}
